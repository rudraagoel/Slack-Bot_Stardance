---

## The commands are as follows:

###  `/radbot-greet`

Greets you politely.

###  `/radbot-funfact`

Get a random fact about **science, literature, philosophy, and other cool topics.**

###  `/radbot-catfact`

Get a random fact about cats.

###  `/radbot-joke`

Get a random joke!

### `/radbot-help`

Show all commands.
